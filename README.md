# Disciplina 2.0 — Planner de Treino Híbrido

Planner de 8 semanas (musculação Upper/Lower + corrida) feito em um único arquivo HTML, pensado para o celular.

## Recursos
- Treino por dia da semana, com séries, reps mín–máx e descanso
- Registro de carga por série e sugestão automática da próxima carga (dupla progressão)
- Cronômetros de descanso e de intervalos de corrida
- Dieta por dia, com troca de alimentos e recálculo de kcal e macros
- Revisão semanal, guia de técnicas e mentalidade
- Tema claro e escuro automáticos

## Como usar
Acesse pelo GitHub Pages e use "Adicionar à Tela de Início" no Safari.
Os registros ficam salvos no navegador do aparelho. Use "Copiar backup" na aba Guia antes de trocar de aparelho.

## Tecnologia
HTML, CSS e JavaScript puros, sem dependências.
